Linear Search

Sequentially checks each element until a match is found. Time: O(n) | Space: O(1)

Pseudocode

function linearSearch(arr, target):
  for i = 0 to arr.length - 1:
    if arr[i] == target:
      return i       // Found at index i
  return -1          // Not found

Binary Search

Requires sorted array. Halves the search space each step. Time: O(log n) | Space: O(1)

Pseudocode

function binarySearch(arr, target):
  left = 0, right = arr.length - 1
  while left <= right:
    mid = (left + right) / 2
    if arr[mid] == target: return mid
    elif arr[mid] < target: left = mid + 1
    else: right = mid - 1
  return -1

Bubble Sort

Repeatedly swaps adjacent elements if out of order. Time: O(n²) | Space: O(1)

Pseudocode

function bubbleSort(arr):
  n = arr.length
  for i = 0 to n-1:
    for j = 0 to n-i-2:
      if arr[j] > arr[j+1]:
        swap(arr[j], arr[j+1])
  return arr
